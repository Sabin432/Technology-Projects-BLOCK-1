## Conversion from One Base to Another
1. **Convert the decimal number 156 to:**
   - Binary
   - answer; 156=10011100
   - Octal
   - answer; 156=234
   - Hexadecimal
   - answer; 156=9C

2. **Convert the binary number 101101 to:**
   - Decimal
   - answer; 101101=45
   - Octal
   - answer; 101101=55
   - Hexadecimal
   - answer; 101101=2D

3. **Convert the octal number 745 to:**
   - Decimal
   - answer; 745=485
   - Binary
   - answer; 745=111100101
   - Hexadecimal
   - answer; 745=1E5

4. **Convert the hexadecimal number 3F9 to:**
   - Decimal
   - answer; 3F9=1017 
   - Binary
   - answer; 3F9=001111111001
   - Octal
   - answer; 3F9=1771
