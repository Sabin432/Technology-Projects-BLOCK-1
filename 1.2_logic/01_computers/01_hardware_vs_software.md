# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---Hardware is known as the physical part of the computer which we can see and touch. for example; keyboard, mouse, printer, CPU etc. Each parts of the computer has the different functions like keyboard is used to types the words, printer is use to print the input and take the results as the output etc. All this part work together to help computer function properly. Hardware is the important part of the computer system because without hardware we cannot use the computer to perform different task.

## Explain Software
Write **at least 50 words** explaining what software is.
---Software is the set of the program that tells a computer to perform different task. it is an important parts of computer system. There are two main types of software they are system software and the application software. System software manage the computer and it's hardware and application software helps to complete the specific task. software example; Google, windows, Microsoft word etc

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make a computer function properly. Hardware refers to the physical part of the computer which we seen an touch and the Software refers to the program and instructions that tell the computer what to do. example; when we type using the keyboard the hardware sends input to the computer and the software process the input and display the results as output.
